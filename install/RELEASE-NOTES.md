Download **Airy-v2.2-Windows-VST3.zip** for Windows (Cubase, FL Studio, Ableton...) or **Airy-v2.2-Mac-AU-VST3.zip** for Mac (Logic Pro uses the AU; works on Intel and Apple Silicon). Install steps are inside each zip and in the README.

Mac users: the plugin isn't signed with an Apple Developer account, so run this once in Terminal after copying the files:
```
xattr -dr com.apple.quarantine ~/Library/Audio/Plug-Ins/Components/"Airy v2.2.component" ~/Library/Audio/Plug-Ins/VST3/"Airy v2.2.vst3"
```
